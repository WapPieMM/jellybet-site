# jellybet — เครดิตร้านและช่องทางติดต่อ

เว็บหน้าเดียว responsive สำหรับมือถือและคอมพิวเตอร์ โทนขาวครีมตัดชมพู มีหน้าเครดิต/รีวิว ช่องทางติดต่อ สถานะร้านเปิด-ปิด และระบบหลังบ้านสำหรับเจ้าของร้าน

## ไฟล์ในโปรเจกต์
- `index.html` หน้าเว็บ
- `styles.css` รูปแบบและการจัดวาง responsive
- `app.js` การทำงานของหน้าเว็บและหลังบ้าน
- `config.js` ตั้งค่า Supabase
- `supabase-schema.sql` สร้างตารางและสิทธิ์การเข้าถึงฐานข้อมูล รวมถึงระบบ Account พร้อมขาย

## ทดลองดูหน้าตาเว็บ
เปิด `index.html` ในเบราว์เซอร์ได้เลย เว็บจะแสดงข้อมูลตัวอย่าง แต่การบันทึกข้อมูลจากหลังบ้านจะยังไม่ทำงานจนกว่าจะตั้งค่า Supabase และเผยแพร่ผ่านเว็บโฮสต์

## ตั้งค่าให้เป็นเว็บใช้งานจริง

### 1. สร้างฐานข้อมูล Supabase
1. เข้า https://supabase.com/ แล้วสร้างโปรเจกต์ใหม่
2. ไปที่ **SQL Editor** แล้วเปิดไฟล์ `supabase-schema.sql` คัดลอกเนื้อหาทั้งหมดไปวางและกด Run
3. ไปที่ **Project Settings → API** (หรือหน้า Connect/API Keys ตามหน้าตาแดชบอร์ดปัจจุบัน) แล้วคัดลอก Project URL และ publishable/anon key
4. เปิด `config.js` แล้วแทนค่า `https://YOUR-PROJECT.supabase.co` และ `YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY` ด้วยค่าจริง
   - ใช้ได้เฉพาะ publishable/anon key ในหน้าเว็บ
   - **ห้ามใส่ service_role/secret key ในไฟล์เว็บ** เพราะทุกคนสามารถดูไฟล์ JavaScript ที่เผยแพร่แล้วได้

### 2. สร้างบัญชีเจ้าของร้าน
1. ใน Supabase ไปที่ **Authentication → Users → Add user** สร้างผู้ใช้ด้วยอีเมลของเจ้าของร้านและรหัสผ่านที่คาดเดายาก
2. เปิดรายละเอียดผู้ใช้ แล้วตั้งค่า **App Metadata** ให้มี JSON นี้: `{ "role": "admin" }` (ต้องเป็น App Metadata ไม่ใช่ User Metadata)
3. บันทึกการเปลี่ยนแปลง หากเปิดหน้าเว็บค้างไว้ ให้รีเฟรชแล้วเข้าสู่ระบบใหม่
4. กลับหน้าเว็บ กด **สำหรับเจ้าของร้าน** แล้วเข้าสู่ระบบด้วยบัญชีที่สร้างไว้

นโยบาย RLS ใน SQL จะอนุญาตให้ผู้ใช้ที่มี `app_metadata.role = admin` เพิ่ม/แก้ไข/ลบรีวิวและ Account รวมถึงแก้ไขข้อมูลร้านได้เท่านั้น ผู้เข้าชมทั่วไปอ่านข้อมูลหน้าร้าน รีวิวที่เผยแพร่แล้ว และรายการ Account ได้

### 3. รูปภาพและการส่งรีวิว
- SQL จะสร้าง bucket `review-images` และ `shop-images` จำกัดชนิดรูปและขนาด 5 MB
- ลูกค้าส่งรีวิวและแนบรูปได้โดยไม่ต้องสมัครบัญชี แต่รีวิวจะยังไม่แสดงจนกว่าเจ้าของร้านอนุมัติ
- หลังบ้านสามารถอัปโหลดรูปโปรไฟล์ร้านและรูปปกได้จากเครื่องหรือมือถือ
- เนื่องจากไฟล์รูปใน bucket เป็น public เพื่อให้แสดงบนหน้าเว็บได้ อย่าอัปโหลดหลักฐานที่มีข้อมูลส่วนตัวหรือข้อมูลชำระเงินที่ยังไม่ปิดบัง

### 4. เผยแพร่เว็บไซต์ (ตัวอย่าง: Netlify)
1. ไปที่ https://app.netlify.com/ แล้วสมัคร/เข้าสู่ระบบ
2. ลากโฟลเดอร์ `jellybet-site` (หรืออัปโหลดไฟล์ทั้ง 5 ไฟล์) ไปยังส่วน deploy แบบ manual ของ Netlify
3. รอให้ Netlify สร้างลิงก์เว็บไซต์ จากนั้นเปิดลิงก์บนมือถือเพื่อตรวจสอบ
4. เปลี่ยนชื่อเว็บย่อยได้จาก Site configuration / Domain management และสามารถผูกโดเมนของตัวเองภายหลังได้

อีกทางเลือกคือ Vercel: สร้าง Git repository ใส่ไฟล์ทั้งหมด แล้ว Import Project ใน https://vercel.com/ โดยใช้ static site ได้เลย ไม่ต้อง build command

## วิธีใช้งานหลังบ้าน
- **ข้อมูลร้าน**: แก้ชื่อร้าน ข้อความแนะนำ ช่องทาง LINE, X, Instagram, Facebook และสถานะเปิด/ปิด แล้วกดบันทึก ชื่อร้านจะเปลี่ยนตามกันทั้งหัวเว็บ ชื่อแท็บเบราว์เซอร์ คำอธิบายหน้าเว็บ ส่วนตกแต่ง ท้ายเว็บ และหัวข้อหลังบ้าน โดยบันทึกถาวรในคอลัมน์ `site_settings.shop_name`
- **จัดการรีวิว**: เพิ่มชื่อที่ใช้แสดง คะแนน ข้อความ และลิงก์รูปหลักฐาน เลือกว่าจะเผยแพร่หรือซ่อนไว้
- รีวิวใหม่จากลูกค้าจะถูกบันทึกเป็นรอตรวจสอบ (published=false) โดยอัตโนมัติ เจ้าของร้านเข้าสู่ระบบเพื่อเผยแพร่ ซ่อน แก้ไข หรือลบได้
- ข้อมูลถูกเก็บใน Supabase จึงไม่หายเมื่อผู้เข้าชมปิดหน้าเว็บหรือเปลี่ยนอุปกรณ์

## หมายเหตุสำคัญ
- ก่อนเปิดใช้จริง ให้ทดสอบล็อกอิน/ออกจากระบบ และตรวจสอบว่าไม่มีผู้ใช้ทั่วไปแก้ไขข้อมูลได้
- ลูกค้าและเจ้าของร้านสามารถอัปโหลดรูปจากมือถือ/คอมพิวเตอร์ได้ ระบบเก็บไฟล์ไว้ใน Supabase Storage และเก็บ URL ในฐานข้อมูล ควรเผยแพร่เฉพาะหลักฐานที่ได้รับอนุญาตจากลูกค้า และปิดบังข้อมูลส่วนตัว/ข้อมูลการชำระเงินก่อนเสมอ
- ปุ่มหัวใจเป็นเอฟเฟกต์บนหน้าเว็บ ไม่ได้บันทึกเป็นบัญชีผู้ใช้
- เวอร์ชันเริ่มต้นนี้ใช้ระบบล็อกอิน Supabase; ไม่มีการเก็บรหัสผ่านในเว็บไซต์เอง


## ปรับแต่งธีมเว็บไซต์จากหลังบ้าน
หลังตั้งค่า Supabase และเข้าสู่ระบบด้วยบัญชีแอดมินแล้ว ให้เปิดแท็บ **ปรับแต่งธีม** เลือกธีม Coquette / Pastel Pink / Rose Vintage / Vanilla Cream หรือเลือกสีเองได้ 5 ส่วน ได้แก่ สีพื้นหลัง สีการ์ด สีหลัก สีอ่อน และสีตัวอักษร จากนั้นกด **บันทึกธีมเว็บไซต์** การตั้งค่าจะถูกบันทึกใน `site_settings` และใช้กับผู้เข้าชมทุกคน

หากใช้ฐานข้อมูลเดิม ให้รัน SQL ในไฟล์ `supabase-schema.sql` อีกครั้งใน Supabase SQL Editor เพื่อเพิ่มคอลัมน์ธีมใหม่ (คำสั่งใช้ `ADD COLUMN IF NOT EXISTS` จึงรองรับตารางเดิม) แล้วรีเฟรชเว็บไซต์

การเปลี่ยนรูปโปรไฟล์/ปกและแนบรูปรีวิวทำได้จากเครื่องหรือมือถือผ่านช่องอัปโหลดในหลังบ้าน/แบบฟอร์มรีวิว โดยรูปจะถูกส่งไปยัง Supabase Storage เมื่อเชื่อมต่อโปรเจกต์แล้ว


## ระบบ Account พร้อมขาย
- หน้า `Account พร้อมขาย` แสดงรูป รายละเอียด ราคา และสถานะ “พร้อมขาย / ขายแล้ว”
- เจ้าของร้านเข้าสู่ระบบ แล้วเปิดแท็บ **จัดการ Account** เพื่อเพิ่ม แก้ไข ลบ และเปลี่ยนสถานะรายการได้
- รูป Account อัปโหลดไปยัง Supabase Storage bucket `account-images` รองรับ JPG, PNG, WEBP และ GIF ขนาดไม่เกิน 5 MB
- รายการบันทึกในตาราง `accounts` และแสดงต่อผู้เข้าชมทุกคน
- **สำคัญ:** หลังอัปเดตโค้ด ให้เปิด Supabase SQL Editor แล้วรันไฟล์ `supabase-schema.sql` เวอร์ชันใหม่อีกครั้งเพื่อสร้างตาราง `accounts`, bucket และ RLS policies ใหม่ (คำสั่งส่วนนี้ใช้ `IF NOT EXISTS` / `DROP POLICY IF EXISTS` จึงรองรับฐานข้อมูลเดิม)
- ปุ่มสนใจรายการจะพาไป LINE ที่ตั้งไว้ในข้อมูลร้าน หากยังไม่ได้ตั้ง LINE จะพาไปส่วนช่องทางติดต่อ
